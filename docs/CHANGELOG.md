- Gitタグ：`v0.0.6`

- [Issue #7](https://github.com/aespawinter0620-boop/sekasoko-piece/issues/7)：弓兵「支援射撃」、騎士「鼓舞」、ゴーレム「守護の石壁」の自動パッシブを追加。共通の `PASSIVES`、`PASSIVE_LOADOUTS` と戦闘情報APIへ集約。
- 支援は通常攻撃の起点者を除く生存弓兵が、元対象への射程を満たす場合にID文字列順で各1回行う。実効ATKの100%を使い、追撃の連鎖を行わない。元対象または王の撃破で止める。
- 鼓舞は攻撃時点の上下左右の生存味方騎士を自身抜きで数え、`floor(基礎ATK*(1+0.5*人数))` を通常攻撃と各追撃へ適用。
- 守護は元対象に隣接する生存味方ゴーレムを現在HP最大・同値ならID文字列順で選び、そのヒットの受け手だけを変更する。王も保護でき、超過ダメージの転送と守護の再帰は行わず、各ヒットで再選択。
- 通常攻撃と支援を1行動として解決し、元対象と実際の受け手、各ヒット前後のHP、追撃フラグをイベントへ記録。撃破・候補・勝敗を各ヒットで処理し、手番と報酬の重複処理を防ぐ。
- `predictAttack` は実戦と同じ解決処理を独立したコピーへ適用し、入力状態を変更せずに実ダメージ・撃破・守護・支援・王の撃破を予測。AIはこの予測を評価に共有する。
