Chromium、deviceScaleFactor 1で2026年11月26日に取得した未加工スクリーンショット。実機Safariの画像ではない。

- [390×844・初期24体](390x844-initial.png)
- [844×390・初期24体](844x390-initial.png)
- [320×568・多数所持の編成](320x568-large-formation.png)

初期盤面は通常の新規探索。編成画面は検証専用のメモリー上の状態から、11体の獲得と合計102体の所持を作って実際のUI操作で開いた。画像は一覧の末尾までスクロールした状態で、次階層ボタンを確認できる。

[8画面サイズの寸法記録](comparison.json) はVER.005の各領域の実測値を含む。`old` と面積比はVER.003との比較値を継続記録したもの。自動検証では別に、同じ環境で描画したVER.004の基準値との一致を確認している。盤面・枠・HUD・ステータス領域の寸法と位置を維持し、マス比率0.90、24体のHP・駒のタップ先を検証した。数値指定したセーフエリアも自動検証するが、実際のiPhoneのノッチやSafariのツールバー挙動は実機で確認する。
