盤面・枠・HUD・ステータスの外寸とマス比率0.90は維持し、連携の説明は固定ステータス内部だけをスクロールして確認する。自動検証では8画面サイズ、数値指定のセーフエリア、守護・通常攻撃・撃破・追撃の途中での回転も確認する。
