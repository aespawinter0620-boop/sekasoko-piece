初期軍団は通常の新規探索。22手駒と演出の分岐は検証用のメモリー上の戦闘状態を作り、実際の手駒ボタンと盤面から操作した。22体は王を除く1戦の全個体数で、手駒保有数に追加の上限は設けていない。

[8サイズのVER.006との比較](comparison.json) に、盤面・枠・HUD・ステータス外寸の測定値と差を保存した。手駒欄の追加は情報パネル内部の圧縮で収め、盤面・マス比率0.90・縦横配置を維持。小さい画面でも能力とパッシブの全文には「詳細」からアクセスできる。

手駒の同一個体ID、両軍の横スクロールとクリック、ドラッグの誤選択防止、手駒選択中および再出撃中の回転、満HP、演出中入力拒否、AI応答1回を自動検証した。アイコンは同梱の `assets/icons/` を使う。
